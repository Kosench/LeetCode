# 977. Квадраты отсортированного массива (Squares of a Sorted Array)
**Уровень:** Easy

## Условие
Дан целочисленный массив `nums`, отсортированный в неубывающем порядке. Верните массив квадратов каждого числа, также отсортированный в неубывающем порядке.

## Примеры
**Пример 1:**
```
Ввод: nums = [-4,-1,0,3,10]
Вывод: [0,1,9,16,100]
```
*Пояснение:* После возведения в квадрат массив становится `[16,1,0,9,100]`. После сортировки: `[0,1,9,16,100]`.

**Пример 2:**
```
Ввод: nums = [-7,-3,2,3,11]
Вывод: [4,9,9,49,121]
```

## Ограничения
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` отсортирован в неубывающем порядке.

## Follow up
Возведение в квадрат и последующая сортировка дают `O(n log n)`. Сможете ли вы найти решение за `O(n)`, используя другой подход?
