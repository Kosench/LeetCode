# 75. Сортировка цветов (Sort Colors)

**Сложность:** Средняя (Medium)

## Условие задачи
Дан массив `nums` из `n` объектов, окрашенных в красный, белый или синий цвет. Отсортируйте их *на месте* (in-place) так, чтобы объекты одного цвета находились рядом, а цвета располагались в порядке: красный, белый, синий.

Мы будем использовать целые числа `0`, `1` и `2` для представления красного, белого и синего цветов соответственно.

**Важно:** Вы должны решить эту задачу, не используя встроенную функцию сортировки библиотеки.

## Примеры

**Пример 1:**
- **Ввод:** `nums = [2,0,2,1,1,0]`
- **Вывод:** `[0,0,1,1,2,2]`

**Пример 2:**
- **Ввод:** `nums = [2,0,1]`
- **Вывод:** `[0,1,2]`

## Ограничения
- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` равно `0`, `1` или `2`.

## Дополнительное задание (Follow up)
Сможете ли вы придумать алгоритм за **один проход** (one-pass), использующий только **константное** дополнительное пространство?

---
> [!info] Подсказка для Go
> Это классическая задача «Голландский национальный флаг» (Dutch National Flag problem).
> Оптимальное решение использует три указателя: `low` (для 0), `mid` (текущий элемент) и `high` (для 2).
> Алгоритм работает за $O(n)$ времени и $O(1)$ памяти.
